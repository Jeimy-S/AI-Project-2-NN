# PROJECT 2 – Fully Connected Neural Networks

# Overview
This project implements fully connected neural networks using PyTorch for both regression and classification tasks.
- Regression: Predict car MPG using the Auto MPG dataset
- Classification: Classify handwritten digits using the MNIST dataset

# Models
Three different neural network architectures were implemented and compared for each task.
- Regression:
    - Network 1: 1-layer model
    - Network 2: 4-layer model
    - Network 3: 5-layer model
- Classification:
    - Network 1: 4-layer model
    - Network 2: 6-layer model
    - Network 3: 6-layer model

# Training
- Epochs: 20
- Learning Rate: 0.01
- Activation: ReLU (hidden layers)

# Results
Models were evaluated using loss and accuracy metrics. The best-performing models were selected based on validation performance.
